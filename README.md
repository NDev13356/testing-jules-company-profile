# Creative Portfolio — Next.js

Dark, modern portfolio website for a Designer/Creative. Built with Next.js 14, TailwindCSS, and Framer Motion.

## Stack
- Next.js 14 (App Router)
- TypeScript
- TailwindCSS
- Framer Motion
- React Hook Form
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
